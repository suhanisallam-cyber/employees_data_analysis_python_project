# Employee Data Analysis using Python

##  Project Overview

This project focuses on analyzing employee data using Python to understand employee demographics, departments, salaries, experience, and other key patterns.
The project demonstrates data analysis and visualization skills using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

##  Project Objectives

- Analyze employee data using Python
- Understand department-wise employee distribution
- Analyze salary and experience patterns
- Explore employee demographics
- Identify useful insights from the dataset
- Create visualizations to present the findings clearly

##  Technologies & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- vs code

## 📂 Dataset

The dataset contains 30 employee records with the following columns:

- Employee_ID
- Name
- Age
- Gender
- Department
- Salary
- Experience
- Joining_Date
- City

## 🔍 Analysis Performed

The following analysis was performed:

1. Loaded and inspected the employee dataset
2. Checked data types and dataset structure
3. Checked for missing values
4. Analyzed employee distribution by department
5. Analyzed salary information
6. Compared employee experience
7. Analyzed employee demographics
8. Created charts and visualizations
9. Extracted useful insights from the data

##  Key Findings

- The dataset contains **30 employees**.
- The **IT department** has the highest number of employees with 11 employees.
- Finance has 7 employees.
- HR has 6 employees.
- Sales has 6 employees.
